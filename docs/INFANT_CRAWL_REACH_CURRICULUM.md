# 乳児ハイハイ：手の前進再接地を要求する実験

MIMo乳児モデルの拮抗筋、身体15領域の接触法線力、触覚依存ステッパーをIsaac Lab/Newton上で実行した。モデルと場面の生成・身体感覚予測・立位への試行は[発達実験の全体記録](DEVELOPMENTAL_HUMAN.md)を参照。使用環境はRTX 5090、Isaac Lab `v3.0.0-EA-26-gbe270ed88-dirty` で、正式版3.0.0は未検証。

従来のステッパーは手の離地と再接地だけで一歩と数え、前に進まない再接地も含んでいた。今回、骨盤根元に対する中手骨中心の前後位置がスイング開始時から3 cm以上進んだ再接地だけを完了とした。これは剛体中心の測定であり、掌の接触点や柔軟皮膚の移動量ではない。既存の接触予測特徴付き方策を未知seed 9601/9603/9607、各8体×16秒で再評価すると、旧定義の完了13回のうち前進条件を満たすものはIsaac Lab/Newtonで3回だった。持続ハイハイは0/24体。

この条件と支持中の遊脚前方到達報酬でPPOを16更新、8体×16秒/更新だけ継続した。未知seed 9801/9803/9807各8体×16秒を同じ初期姿勢・同じ3 cm条件で比較した結果は次の通り。

| 指標（24体平均） | 元方策 | 16更新後 |
|---|---:|---:|
| 3 cm前進再接地回数/体 | 0.167 | 0 |
| 掌＋下腿の高姿勢支持時間率 | 86.97% | 76.17% |
| 最後4秒の同支持時間率 | 72.50% | 39.74% |
| 胴体前進距離 | −0.0348 m | −0.0078 m |
| 厳格な持続ハイハイ達成 | 0/24 | 0/24 |

途中8更新目を別の未知seed 9911/9913/9917各8体でも評価した。元方策→途中重みで支持は65.87→75.68%となったが、3 cm再接地は0.333→0.083回/体、平均胴体前進は+0.0021→−0.0036 m、持続ハイハイは双方0/24体。支持と前進到達の両立はできていない。報酬に用いた中手骨座標は特権的なシミュレータ状態であり、触覚だけから身体図式を獲得した証拠ではない。歩行も未達成。

同一初期状態seed 9803・代表個体の[16秒比較動画](../artifacts/infant-development/infant_crawl_reach_comparison_latest_2026-10-03.mp4)は、左が元方策、右が16更新後の方策。物理計算で記録した関節姿勢を後処理で描画し、描画時に力学は再積分していない。動画に表示した指標は動画用の再実行結果であり、上記24体集計とは独立した試行である。対応する動画用姿勢データ、評価JSON、重み、姿勢初期値は `artifacts/infant-development/` に置く。元のMIMoモデルアセットは含めない。

コードの入口は `examples/isaaclab_newton_fullbody/evaluate_infant_newton_crawl.py`、`train_infant_newton_stepper_ppo.py`、`render_infant_crawl_comparison.py`。動画用記録は評価コマンドの `--save-qpos` で保存できる。姿勢動画が示すのは現状の運動であり、ハイハイ獲得の成功例ではない。
